Project overview · Utah State Agricultural Technology Club

Agg Tech Club Finances

A web app for tracking the club's money and projects in one place: who funds each project, what comes in, what gets spent, and how much is left in each account.

What users can do

  • Add a record with a simple form
  • Browse every record in a list, and open any one to see its full details
  • Delete records, with a warning before anything linked is removed too
  • Mark a purchase as resolved once it's paid
  • See both account balances at a glance on the dashboard

How money moves

$4,000 → ExpensesRecorded automatically as the budget for each new project
$1,000 → OperationsRecorded automatically for the club's general fund with each new project
Purchases −Reduce the project budget right away, and the account balance once resolved

Open questions

  1. Should the app require people to log in? If so, who gets access, and should some users (like the treasurer) be able to do more than others?
  2. How should project teams be tracked? Is a simple list of names enough, or should each member have their own record?
  3. What else should a project record? For example: start and end dates, a faculty advisor, goals, or statuses beyond active and inactive.
  4. Should records be editable after they're created, or only deleted and re-entered?
  5. Will the $4,000 and $1,000 amounts per project always stay the same?
  6. Are there any other features this project needs?
Built on the club's existing web app starter (React, Express, PostgreSQL). Detailed requirements are tracked as issues in Linear.
